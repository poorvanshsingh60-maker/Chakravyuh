# Chakravyuh — Combinatorial Interview Orchestration Engine

Autonomous interview loop scheduling platform powered by Google OR-Tools CP-SAT constraint optimization.

## Quick Start
1. `npm install`
2. `npm run dev`
3. Open http://localhost:3000 in your browser!

## Perspectival Architecture
- **Candidate Portal**: ModernLoop-style personalized candidate experience, meeting links, and interviewer briefs.
- **Coordinator Matrix**: Multi-track resource timeline (rooms, pods, interviewers) with live CP-SAT optimization controls and version publishing.
- **Interviewer Hub**: Weekly availability management, assigned interview rooms, and official evaluation scorecard drawer.
- **Load Analytics**: Interviewer burnout guard, load balance standard deviations, and pod occupancy rates.
